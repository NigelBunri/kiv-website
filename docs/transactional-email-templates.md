# Transactional email templates

Each template must include why the recipient received it, expiry information where applicable, ignore guidance, and support/security contact details. No marketing copy.

## Verify email

Subject: Verify your KIS email address

HTML body: KIV/KIS received a request to verify this email address. Use the verification link before it expires. If you did not request this, ignore the email and contact security support if concerned.

Plain text: KIV/KIS received a request to verify this email address. Use the verification link before it expires. If you did not request this, ignore this email.

## Password reset

Subject: Reset your KIS password

Plain text: A password reset was requested for your KIS account. The link expires soon. If you did not request this, ignore the email and consider contacting security support.

## Login/security code

Subject: Your KIS security code

Plain text: Use this code only to complete the login or security action you requested. It expires soon. KIV/KIS will never ask you to send this code to support.

## Security alert

Subject: Security alert for your KIS account

Plain text: We noticed a security-related change or sign-in attempt for your account. If this was not you, contact security support.

## Organisation invitation

Subject: Invitation to join an organisation on KIS

Plain text: You received this because an organisation invited this email address to join a KIS workspace. Accept only if you recognise the organisation.

## Payment receipt placeholder

Subject: KIS payment receipt

Plain text: This placeholder is not active until payment workflows and compliance are verified. A receipt must explain the transaction, amount, organisation and support path.
